## Critical Disclaimer & Regulatory Stance

**Edu4Loan is an educational decision-support utility. It is NOT a bank, non-banking financial company (NBFC), loan broker, financial intermediary, or official university financial-aid department.**

Edu4Loan does NOT:
- Sanction, approve, or disburse loans.
- Provide legal, tax, or investment advice.
- Rank lenders using subjective scoring, sponsored placements, or algorithmic bias.
- Act as an agent or authorized partner of any commercial bank or government agency.
- Collect, hold, or sell sensitive student personal identification numbers or bank account credentials.

**The lending bank / financial institution remains exclusively responsible for:**
- Assessing borrower and co-borrower creditworthiness (including CIBIL / credit bureau scoring).
- Vetting legal title, valuation, and documentation for collateral.
- Determining final applicable interest rates, risk spreads, and processing fees.
- Formal sanctioning, rejection, execution of loan agreements, and disbursement of funds.

All figures, interest rate ranges, government concessions, and documentation rules displayed on this platform are compiled from public circulars, university notifications, and statutory guidelines. They are provided strictly for informational planning purposes.

## Core Architectural Principles

1. **Zero Artificial Ranking & Commercial Neutrality**
   Banks and loan schemes are presented factually with zero subjective badges such as "Best Bank", "Top Choice", or "#1 Recommended". Results are sorted purely by objective user-selected criteria (e.g., lowest starting interest rate, maximum quantum, or collateral threshold). No paid or sponsored listings exist.

2. **Strict Financial Data Provenance**
   Every financial rate, margin ratio, moratorium policy, and processing fee carries an immutable verification trail:
   - Numerical value and interest calculation formula.
   - Primary authoritative source (RBI, Ministry of Education, Indian Banks Association, Bank circulars, or VIT Bhopal administrative desks).
   - Direct link to official source documentation.
   - Timestamped verification date and status (`verified`, `needs_verification`, or `expired`).

3. **Impartial Conditional Phrasing**
   To avoid misleading prospective borrowers, platform intelligence communicates with conditional precision:
   *"Based on the entered criteria, this scheme may align with your requirements. Final sanction and rate terms are determined solely by the issuing lender."*

4. **FinTech x EdTech UI Design System**
   Constructed around a purpose-built design language tailored to student decision-making:
   - Deep royal blue palette (`#0F172A`, `#1E3A8A`, `#2563EB`) reflecting institutional trust and financial clarity.
   - Accessible, high-contrast typography, readable tables, and interactive amortization curves.
   - Responsive layouts across desktop, tablet, and mobile viewpoints.
   - Color-coded audit tags (green for verified, amber for audit due, blue for official guides).

## Institutional Scope & VIT Bhopal Realities

Edu4Loan addresses the specific geographic, administrative, and academic realities encountered by undergraduate and postgraduate students at **VIT Bhopal University** (located at Kothri Kalan, Sehore District, Madhya Pradesh):

- **Campus Branch Ecosystem**: Detailed operating hours, nodal desks, and verified loan officer contacts for on-campus and nearby bank branches (State Bank of India, Punjab National Bank, Canara Bank, Indian Bank, Bank of Baroda).
- **Fee Schedules & Inclusions**: Comprehensive breakdown of tuition tiers (Category 1 to Category 5), specializations, hostel room types (AC/Non-AC, 2/3/4/6 bedded), and mess charges recognized under education loan budgets.
- **Administrative Clearances**: Step-by-step guidance for obtaining required university paperwork (Bonafide Student Certificate, Official Fee Structure Estimate Letter, Admission Letter) from the VIT Bhopal Finance and Student Welfare offices.
- **Geographic Jurisdictions**: Explanations of home-branch vs. campus-branch loan sanction procedures and parent co-borrower jurisdictional requirements.

## Monorepo Structure & Technology Stack

The project is organized as a clean TypeScript monorepo with strict shared type safety:

```
edu4loan/
├── ARCHITECTURE.md          # Complete architectural specification & data flow design
├── PROJECT_PROGRESS.md      # Live phase-by-phase implementation tracker (Phases 0–12)

├── assets/                  # Platform branding assets and banners
│   └── banner.jpg           # Official Edu4Loan platform banner
├── shared/                  # Shared TypeScript contracts & schemas
│   ├── types/               # Bank, Scheme, Application, Calculator, Document interfaces
│   └── constants/           # Regulatory limits, CGFSEL thresholds, document taxonomy
├── backend/                 # Node.js + Express REST API + MongoDB
│   ├── src/
│   │   ├── config/          # Environment configuration, database connection
│   │   ├── models/          # Mongoose data models with strict indexes
│   │   ├── controllers/     # Financial query controllers and calculation logic
│   │   ├── services/        # Calculation engine, verification safeguards, audit service
│   │   ├── routes/          # Express route declarations with rate-limiting & validation
│   │   ├── seed/            # Authoritative production & demo seed data sets
│   │   ├── scripts/         # Production seed runners, data quality auditor, demo reset
│   │   └── tests/           # Automated test suites (Phases 2, 3, 4)
│   └── tsconfig.json        # Strict TypeScript configuration
└── frontend/                # React 18 + TypeScript + Vite + Tailwind CSS
    ├── src/
    │   ├── api/             # Typed API client with graceful fallback architecture
    │   ├── components/      # UI component library (Button, Card, Badge, Modal, Input)
    │   ├── layout/          # Navbar, Footer, Mobile Drawer, Layout Wrapper
    │   ├── pages/           # 12 page views implementing the 22 modules
    │   ├── context/         # Student Application Context with local persistence
    │   ├── utils/           # Financial formatting and calculation helpers
    │   └── test/            # Component & Integration test suites (Phases 7–12)
    ├── vite.config.ts       # Vite bundler configuration
    └── tailwind.config.js   # Tailored FinTech color palette and typography
```

### Technology Stack Highlights

- **Shared Domain Layer**: Pure TypeScript interfaces and types preventing drift between client and server.
- **Backend**: Node.js, Express, MongoDB, Mongoose, Helmet security headers, CORS protection, express-rate-limit, Jest, Supertest.
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Recharts for financial visualization, Vitest, React Testing Library.

## Getting Started & Local Development

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm (v9.0.0 or higher)
- MongoDB instance (local or MongoDB Atlas connection string)

### 1. Environment Configuration

#### Backend Configuration
Create a `.env` file inside the `backend/` directory:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/edu4loan
CORS_ORIGIN=http://localhost:5173
JWT_SECRET=your_development_jwt_secret_key_here
```

#### Frontend Configuration
Create a `.env` file inside the `frontend/` directory:

```env
VITE_API_URL=http://localhost:5000/api
```

---

### 2. Backend Installation & Operation

Navigate to the `backend/` directory:

```bash
cd backend
npm install

# Run automated test suites (58 passing tests)
npm test            # Phase 2 Foundation suite
npm run test:phase3 # Phase 3 Ingestion & Seed Engine suite
npm run test:phase4 # Phase 4 Production REST API suite

# Ingest Authoritative Production Seed Data
npm run seed:production

# Ingest Supplemental Taxonomies
npm run seed:documents   # Official document taxonomy
npm run seed:government  # PM-Vidyalaxmi, Vidya Lakshmi, CSIS schemes

# Data Quality & Maintenance Utilities
npm run data:quality     # Generates comprehensive data health & freshness report
npm run data:reset-demo  # Safely cleanses demo records without affecting production data

# Build & Start Backend Server
npm run build
npm start
```

---

### 3. Frontend Installation & Operation

Navigate to the `frontend/` directory:

```bash
cd frontend
npm install

# Run automated test suites (98 passing tests)
npm test

# Verify TypeScript compilation and production bundle
npm run build

# Start local development server
npm run dev
```

The frontend application will launch at `http://localhost:5173`.

## Security, Privacy & Integrity Safeguards

- **Zero PII Exposure**: Edu4Loan does not persist Aadhaar numbers, Permanent Account Numbers (PAN), or banking passwords.
- **Graceful Client Fallbacks**: The frontend client includes complete, resilient offline mock data adapters ensuring full platform utility even if backend connectivity is temporarily interrupted.
- **Rate-Limiting & Security Headers**: All API endpoints are protected with Helmet security headers, CORS origin restrictions, and request rate-limiters.
- **Data Integrity & Freshness Daemon**: Automated auditing tools identify any bank rate or scheme document that exceeds 90 days without explicit administrative review.
